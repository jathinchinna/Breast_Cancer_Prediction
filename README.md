# Breast Cancer Classification using Machine Learning

This project applies multiple machine learning algorithms to classify tumors as benign(Non-cancerous tumor) or malignant(Cancerous tumor) using the Breast Cancer Wisconsin dataset.

## Dataset
- [Breast Cancer Wisconsin (Diagnostic) Data Set]

## Tools & Libraries
- Python, Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- SMOTE (Imbalanced-learn)

## Models Implemented
- Random Forest
- K-Nearest Neighbors (KNN)
- Logistic Regression
- Naive Bayes

## Techniques
- Feature scaling
- Label encoding
- Train-test split
- SMOTE for class balancing
- Confusion matrix, precision, recall, F1 score, ROC-AUC

## Results
- Best Accuracy: 97%
- Best AUC: 1.00 (Random Forest)

- Confusion Matrices
- ROC Curve Comparison
